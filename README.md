# GC Logistic Website

A responsive bilingual (Arabic/English) static website starter for GC Logistic.

## Files
- `index.html` — page structure and content
- `styles.css` — responsive visual design
- `script.js` — language switching and mobile navigation

## Preview locally
Open `index.html` in a browser.

## Publish with GitHub Pages
1. Upload the three website files to the repository root (same level as README.md).
2. Open the repository on GitHub.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then Save.
6. GitHub will show the published website URL in the Pages section.

## Before public launch
Replace the temporary contact placeholders in `index.html` and update the company profile, logo, service scope, and contact details using the approved company information. No backend contact form is included in this static first version.
